# Installation and Quick Start

## Installation

Modifier State Vault uses Blender's Extension format.

1. Keep the distributed `modifier_state_vault-1.1.0.zip` intact.
2. Open Blender.
3. Open **Edit > Preferences**.
4. Open **Get Extensions**.
5. Open the menu in the upper-right corner.
6. Choose **Install from Disk**.
7. Select `modifier_state_vault-1.1.0.zip`.
8. Enable the extension if needed.
9. In the 3D Viewport press **N** and open **State Vault**.

## Quick test

1. Select one or more objects with modifiers.
2. Open **N > State Vault**.
3. Set Scope to **Selected**.
4. Set Boost Mode to **All**.
5. Click **BOOST VIEWPORT**.
6. Confirm the target viewport modifiers are disabled.
7. Click **RESTORE EXACT STATES**.

The previous mixed viewport state should return exactly.
