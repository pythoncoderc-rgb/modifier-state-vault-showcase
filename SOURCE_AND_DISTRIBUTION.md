The marketplace-distributed extension package contains the Python source files required by the add-on and the applicable license text.

This public repository is intentionally a **product showcase** containing documentation, screenshots, GIF media, and release/testing notes. It does **not** mirror the customer release ZIP or the private development/test repository.

The private development repository is used for release engineering, regression tests, persistence tests, and frozen release artifacts.
